# 💕 For Amanjalee - A Special Website

A beautiful, romantic website created with love, featuring a magic word entry system and a special reveal page.

## Features

- ✨ Beautiful pink-themed design
- 💖 Magic word entry system (Magic word: **Amanjalee**)
- 📱 Fully responsive for all devices (especially mobile)
- 🌹 Romantic animations and effects
- 💕 Floating hearts and heart rain
- ✨ Smooth transitions and animations
- 🎵 **Favorite Song Section** - Add her favorite song with Spotify/YouTube link
- 💝 **Reasons I Love You** - Beautiful grid of reasons why you love her
- 📸 **Special Memories Timeline** - Timeline of your special moments together
- 💌 **Love Quotes** - Romantic quotes section
- 🖼️ **Photo Gallery** - Placeholder for your photos together
- 💕 **Final Love Message** - Personal message section

## How to Use

1. Open `index.html` in a web browser
2. Enter the magic word: **Amanjalee**
3. Enjoy the special reveal page!

## Hosting on GitHub Pages

To host this website on GitHub Pages:

1. Create a new repository on GitHub
2. Upload all files (index.html, style.css, script.js)
3. Go to Settings → Pages
4. Select the main branch as source
5. Your site will be live at `https://yourusername.github.io/repository-name/`

## Files

- `index.html` - Main HTML structure
- `style.css` - All styling and responsive design
- `script.js` - Interactive functionality and animations

## Customization

### Adding Her Favorite Song
1. Open `index.html`
2. Find the `.play-button` link (around line 60)
3. Replace `href="#"` with her Spotify or YouTube song link
4. Update the song title and artist name in the song info section

### Adding Photos
1. Add your photos to an `images` folder
2. In `index.html`, replace the gallery placeholders with `<img>` tags:
   ```html
   <img src="images/photo1.jpg" alt="Our memory">
   ```

### Customizing Reasons & Memories
- Edit the reasons in the "Reasons Why I Love You" section
- Update the memories in the "Special Moments" timeline
- Modify the love quotes to your favorite ones
